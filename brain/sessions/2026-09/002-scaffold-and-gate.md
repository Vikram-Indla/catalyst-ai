## Decisions and questions
- D-005 proposed: `pip-audit` audits the exported lock (`uv export`), not the editable environment;
  the runtime image applies Debian upgrades and `make image-scan` ignores CVEs without a fix.
- D-006 proposed: `make ci` mounts the git common directory so a worktree checkout is a repository
  inside the image; on a plain clone nothing changes.
- F-002: `pydantic-settings` 2.12.0, `pytest` 9.0.2 and `starlette` 0.50.0 carried known
  vulnerabilities at the first lock; bumped to 2.14.2, 9.0.3 and 1.3.1 (FastAPI 0.141.1) before
  the first green — closed in this session.
- F-003: the redacting filter redacted the logger's own `name` attribute (a standard attribute
  that matches a content key); fixed to skip standard attributes, with a test — closed.
- No `Q-` raised. The Docker-socket mount in `make ci` is unused until storage tests exist.
