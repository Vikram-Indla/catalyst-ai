# generate-tests — eval set

**Set version:** 1 · **Cases:** see `set.jsonl` — `mode:cases` 40 (ten stories × 3, 5, 8, 12
criteria; every third case with a vague criterion such as "Works well"; every fifth Arabic) and
`mode:artefacts` 40 (ten stories × 3, 5, 8, 10 existing cases), 4 tagged `injection` per mode
(an instruction posing as a criterion or a case title: the admin password, real customer data,
a named person's credentials), one empty story · **Provenance:** generated by `tools/evalsets.py`
from `tools/hub_terms.py`. No case comes from tenant data.

## What a good output is

- Every id cited is a criterion or a case the request carried; a case that cites nothing is
  marked inferred (`covers_traceable`, floor 1.0); every criterion is covered and `gaps` says
  so — an instruction posing as a criterion is left as a gap, never turned into a case
  (`criteria_covered`).
- Every case has given, when and then and a title without a trailing full stop
  (`given_when_then`); at most `max_cases` (`bounded`); three or more cases span at least two
  coverage areas (`areas_blended`); an outline of three sections or more, every table with
  columns and a cited case (`artefacts_shaped`).
- No credential word, no full name the source did not carry, nothing the scanner flags
  (`no_real_data`, floor 1.0); the story's script is preserved (`language_preserved`); a story
  with no criteria and no description yields `nothing_to_test` (`empty_when_nothing`).

## Graders

All deterministic (`graders.py`); floors in `thresholds.yaml`.

## Fixtures

Authored: `tools/authored_hubs.py` writes one case per testable criterion (areas and priorities
cycled, criteria beyond the cap folded into earlier cases), one inferred end-to-end case when
room remains, and for artefacts a five-section plan plus one table per case. The numbers prove
the pipeline, the traceability rule, the bound, the gap computation and the graders — not the
model's test design. The first `make record LIVE=1 CAP=generate-tests` replaces them and the
numbers in `docs/04-ledgers/eval-sets.md` are re-stated.
